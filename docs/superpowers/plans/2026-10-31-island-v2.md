# Island v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Native execution was chosen for v1 and carries over). Steps use checkbox syntax.

**Goal:** Apply Charvit's list of changes to Island (new Pomodoro tab, in-app keep-awake setup, pin, tab order, clipboard/shelf/stats/camera changes, Mission Control rule, Calendar tab with event alerts, rounder native look, cyan theme, app icon) and make it ready to go public later.

**Architecture:** Unchanged: `IslandCore` (logic, tested), `IslandUI` (views, panel), `Island` (entry). New logic goes in `IslandCore` with tests; views stay thin.

**Tech Stack:** Swift 6.4 (Swift 5 mode), SwiftUI, AppKit, EventKit, Swift Testing. Same build scripts.

**Spec:** `docs/superpowers/specs/2026-10-31-island-v2-design.md` (and v1 spec for unchanged behavior)

## Global Constraints

- Everything from the v1 plan's Global Constraints still holds, except: the sudoers rule is installed **by the app** for the current user (see Task 6), and `scripts/install-sudoers.sh` and the hard-coded `charvit` are removed.
- Theme is black and cyan: one accent, `IslandTheme.accent` (cyan). No remaining `Color.orange`.
- No git commits unless Charvit asks. Every task ends with a Checkpoint: `swift test` (all green, no warnings).
- Never run the real `sudo`/`pmset` writes or the install prompt in tests; use a fake `CommandRunner`. Tests never touch the real clipboard, camera, calendar or login items.
- Saved settings must survive new fields: loading an old `settings.json` keeps the user's values.
- Idle cost: timers/polls only while their feature is live or visible. Measure CPU for anything new that animates or polls (use `top -l 7 -s 2 -pid`, last 5 samples, 25 s after launch, warm).
- Tests must fail for the right reason before the code is written (RED), as in v1.

## Review Focus

1. Old `settings.json` (no new keys) loads with the user's values intact. [Task 2]
2. Tab order with unknown, missing or duplicate ids never hides a tab or crashes. [Task 2]
3. The sudoers install command is safe for any username and never runs anything but the two `pmset` forms; cancelling the password dialog changes nothing. [Task 6]
4. "Clear All" can't wipe pins by one stray click; deleting an image record deletes its saved PNG. [Task 7]
5. Multi-file zip never overwrites, handles same-named files from different folders, and leaves no staging folder. [Task 8]
6. Mission Control never opens the island or leaves it open. [Tasks 1, 11]
7. An event alert fires once, never for all-day or already-started events, survives sleep, and a day with no events or no permission shows a clear state. [Tasks 12–14]
