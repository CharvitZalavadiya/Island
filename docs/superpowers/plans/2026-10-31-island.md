# Island Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Island, a personal macOS notch app with Pomodoro and mascots, keep awake, clipboard history, a file shelf, and a few utilities, packaged as `Island.app` and `Island.dmg`.

**Architecture:** A Swift package with three targets. `IslandCore` holds all testable logic with no UI. `IslandUI` holds SwiftUI and AppKit views, the notch panel and the mascots. `Island` is a tiny executable that starts the app. A shell script assembles, signs and packages the `.app` and `.dmg`, so no Xcode project file is needed.

**Tech Stack:** Swift 6.4 (Swift 5 language mode), SwiftUI, AppKit, Swift Testing, Vision, ImageIO, AVFoundation, Intents (Focus status), ServiceManagement, `ditto`, `hdiutil`.

**Spec:** `docs/superpowers/specs/2026-10-31-island-design.md`

## Global Constraints

- Only Charvit's current Mac is supported: macOS 27.0.1, Apple Silicon, Xcode 27.1, Swift 6.4. No older macOS, no Intel.
- App Sandbox is off. No Dock icon (`LSUIElement` = true). Bundle ID `com.charvit.Island`; products `Island.app` and `Island.dmg`.
- All data lives in `~/Library/Application Support/Island`.
- Island asks only for Camera, Focus status and Desktop folder access. It never needs Accessibility, Screen Recording, Input Monitoring or Full Disk Access.
- Keep awake runs exactly `/usr/bin/sudo -n /usr/bin/pmset -a disablesleep 1` to start and `... disablesleep 0` to stop. The sudoers rule is exactly `charvit ALL=(root) NOPASSWD: /usr/bin/pmset -a disablesleep 0, /usr/bin/pmset -a disablesleep 1`. The implementer never runs the sudoers script and never edits `/etc`. Tests never run a real `pmset` write.
- Crash protection is next-launch recovery only. There is no watchdog process.
- Clipboard types `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType` and `org.nspasteboard.AutoGeneratedType` are never recorded. History keeps the latest 200 items.
- Island never moves, overwrites or deletes the user's files. Output files get a numbered name instead of overwriting.
- Collapsed with nothing live, Island draws nothing beyond the notch. Wings appear only while something is live and are capped at 110 points per side. Outside the panel's frame, clicks pass through.
- No system notifications. A finished Pomodoro plays a sound and shows the mascot's done mood.
- Signing uses the first `Apple Development` identity in the keychain (currently "Apple Development: Charvit Zalavadiya (777SK22L4R)"). If none exists, fall back to ad-hoc signing and print a warning that permissions may reset.
- The camera runs only while the Camera tab is visible. Idle CPU stays near zero: timers run only while their feature is active or visible.
- **Commits:** do not run `git commit` or `git push` unless Charvit asks. Every task ends with a Checkpoint step (run the tests and, where stated, the build) instead.

## Review Focus

Failure modes the spec implies that are most likely to bite. Each has a test in the task named in brackets.

1. A storage file is corrupt or half-written at launch: Island starts with defaults and keeps the bad file as a backup. [Task 2]
2. The keep-awake minutes field gets empty, `0`, `-5`, `abc`, `1.5`, or a huge number: empty means indefinite, everything else invalid shows a message and starts nothing. [Task 8]
3. The Mac sleeps past a Pomodoro end, or the clock jumps: the phase finishes exactly once and the streak counts once. [Task 5]
4. The display setup changes, or the screen has no notch: the panel repositions, and falls back to a top-center pill. [Tasks 3, 4]
5. File collisions and vanished files: converting a PNG to PNG, zipping twice, or removing an original never overwrites or crashes. [Task 12]
